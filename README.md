# AI---Based-URL-Phishing-Detector
This project is an AI-Based URL Phishing Detection System that utilizes XGBoost and Streamlit to identify and classify malicious or phishing websites. The main objective of this system is to enhance cybersecurity by automatically analyzing URLs and predicting whether they are legitimate or phishing based on various extracted features.
Using XGBoost, a powerful gradient boosting algorithm, the model is trained on a dataset of legitimate and malicious URLs, learning intricate patterns and relationships among URL characteristics such as length, presence of special characters, domain age, and HTTPS usage. The trained model achieves high accuracy and robustness in detecting phishing attempts, even with minimal human intervention. The Streamlit framework is used to build an interactive and user-friendly web interface where users can input any URL and instantly receive the detection result. This project demonstrates the effective integration of machine learning and web application development to tackle real-world cyber threats. It contributes to promoting online safety by enabling quick and reliable phishing detection, making it an essential tool for individuals and organizations in today’s digital environment.
